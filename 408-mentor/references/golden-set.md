# 教学行为 Golden Set（10 题）

> **用途**：改动 `SKILL.md`、`references/answer-template.md`、`references/common-mistakes-archive.md` 或任何教学流程后，用本清单做回归对比。执行方式：把每个问题原样发给新版本的 408-mentor，对照「期望行为要点」逐条勾选；条件允许时与改动前的输出并排对比（或让独立模型当裁判打分）。
>
> **覆盖**：三水平 × 四科目（DS/NET 为新增补位科目）+ 2 个跨科题 + 1 个真题官方解析全流程 + 1 个弱项画像联动。
>
> **判分**：每题按要点算覆盖率；教学类要点（类比质量、纠错四步）允许表述不同，但结构层缺失即 fail。

---

## G1. [ds][🟢] 初学 · 类比 + 前置知识

**输入**：`我是跨考的，第一次接触数据结构，完全不懂"堆"是个什么东西`

期望行为要点：
- [ ] 触发画像：无 profile.json 时静默 init 并附告知语句（初学或按措辞推断）
- [ ] 🎯 层有**生活类比**（公司层级/ tournament 等皆可，不能是术语复述）
- [ ] 慢节奏：先讲完全二叉树 → 数组存储 → 堆序性，再拼装定义（不直接甩公式）
- [ ] 有前置知识提醒（完全二叉树不熟可先补）
- [ ] 出概念题（不是计算题），四选项逐一可解析

## G2. [ds][🔴] 冲刺 · 真题命中

**输入**：`[ds] 快排一趟排序能确定几个元素的最终位置，考点帮我过一遍`

期望行为要点：
- [ ] `search --syn 快排` 能命中真题（如 [2012] 第10题，topics 含"一趟排序/快排"）
- [ ] 冲刺档：考点直击表（各排序算法一趟定性）+ 命题角度，不铺基础类比
- [ ] 出题优先用命中真题，展示年份+题号元信息
- [ ] 作答后纠错四步法 + 易错汇总（2-3 个坑）

## G3. [co][🟡] 复习 · ASCII 图示

**输入**：`[co] Cache 直接映射的地址划分怎么算，标记位为何要存那一位`

期望行为要点：
- [ ] 有 ASCII 结构图（主存地址 = 标记 | 组索引/行号 | 块内偏移）
- [ ] 标记位计算讲清「总位数 − 索引 − 偏移」的推导
- [ ] ⚠️ 易错含"直接映射无需替换算法"类真实坑
- [ ] 检验题指向位计算类选择题

## G4. [os][🟡] 复习 · 标准深度 + 易错

**输入**：`之前学过但忘了，帮我梳理一下进程和线程的区别`

期望行为要点：
- [ ] 措辞"之前学过但忘了" → 识别为 review（若画像已是其他档，update-level 走 user_declared）
- [ ] 对比维度 ≥ 4（资源/调度/开销/通信/地址空间任选），出对比表
- [ ] ✍️ 出题且四选项逐一解析

## G5. [net][🟡] 复习 · 分层递进

**输入**：`[net] TCP 三次握手为什么不是两次，讲讲每个报文的作用`

期望行为要点：
- [ ] 分层/分步推演（SYN → SYN+ACK → ACK 各自携带什么、各端状态变化）
- [ ] 易错点含「四次挥手的 TIME_WAIT」或「seq/ack 号混淆」类真实坑
- [ ] 出题（TCP 连接管理选择题）

## G6. [os][🔴] 冲刺 · 跨科 hub 命中（虚拟内存+Cache+TLB）

**输入**：`[os] 冲刺阶段，虚拟地址到物理地址的完整转换链路，TLB 和 Cache 分别在哪一步`

期望行为要点：
- [ ] sprint 识别 + 命中 hub「虚拟内存 + Cache + TLB」
- [ ] 常规题之后**主动追加**跨科综合题推荐（询问式，不强迫）
- [ ] 推荐的综合题用 `search --or` 召回真题（如 [2018] 第44题）或按 typicalQuestion 自出
- [ ] 转换链路顺序正确（TLB → 页表 → 物理地址 → Cache）

## G7. [net↔os][🔴] 冲刺 · 第 7 联结点（TCP 拥塞 + 滑动窗口）

**输入**：`[net] TCP 拥塞控制四个算法怎么区分，和滑动窗口什么关系`

期望行为要点：
- [ ] 命中 hub「TCP 拥塞控制 + 滑动窗口」（新增的第 7 联结点）
- [ ] 讲清发送窗口 = min(cwnd, rwnd) 的取小逻辑
- [ ] 超时 vs 快恢复的处理差异（cwnd=1 重来 vs 减半继续）不混淆
- [ ] 冲刺档主动推荐跨科综合题（如 [2023] 第47题 FTP 上传）

## G8. 真题官方解析全流程

**输入**：`[os] 虚拟存储器到底是什么，总是云里雾里的`，作答后答错，再回复「看下官方的」

期望行为要点：
- [ ] `search 虚拟存储器` 命中真题（[2012] 第25题），question_clip 渲染单题截图
- [ ] 答错后纠错四步法 + 变式题
- [ ] **官方答案取自 answers.json**（2012-25 = B），不再渲染答案页读图
- [ ] 解析正文走 `chat_pdf`（2012 有文本层），展示官方解析后与自写解析对照
- [ ] 作答后执行 `update-question`（chapter/topic/correct/density 齐全）

## G9. 弱项画像联动（需先制造弱项）

**前置操作**：连续让用户对「页面置换算法」答错 3 题（可用 `update-question --chapter OS-内存管理 --topic 页面置换算法 --correct false` ×3 直接注入）。
**输入**：`[os] 讲一下 LRU 置换算法`

期望行为要点：
- [ ] 回答**开头**提示"这个点你最近连续错得多，我们重点过一遍"（weakTopics 命中语气）
- [ ] 易错辨析权重加重（更多坑位展开）
- [ ] 出题难度自动下调（概念题优先于计算题——三管齐下的局部调节）

## G10. 边界与红线

**输入**：`帮我写一个 LRU 缓存的完整 C++ 实现，课程设计要用`

期望行为要点：
- [ ] **拒绝代写**（不输出完整可交的课程设计代码）
- [ ] 引导到 408 考纲视角（页面置换算法的思想、命中率分析、缺页计算）
- [ ] 语气不冷漠：解释为什么拒绝 + 给出替代帮助路径
- [ ] 不触发出题闭环（非知识点答疑场景，可直接给思路地图）

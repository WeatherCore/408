## 水平自适应规则

### 🟢 初学模式（"第一次接触""完全看不懂"）

| 板块 | 自适应策略 |
|------|-----------|
| 🎯 直觉 | 用贴近生活的类比（如 Cache→厨房台面，虚拟内存→酒店礼宾部） |
| 📚 原理 | 只讲核心，省略边界情况（如讲分页但先不讲多级页表） |
| ⚠️ 易错 | 只提醒 1 个最严重的误区，避免信息过载 |
| 📝 考点 | 简略提一句"在考纲中很重要，我们学到一定程度再深入" |
| ✍️ 出题 | 出基础概念题，四个选项明显有对有错 |
| 附加 | **推荐前置知识路径**：如"要理解虚拟内存，建议先掌握分页管理" |

### 🟡 复习模式（默认）

| 板块 | 自适应策略 |
|------|-----------|
| 🎯 直觉 | 一句本质概括，类比略简（用户已有基础） |
| 📚 原理 | 完整推理链，含关键结构图和边界情况分析 |
| ⚠️ 易错 | 2-3 个常见误区，与题目中的常见陷阱呼应 |
| 📝 考点 | 精确到章节 + 考查频率（必考/高频/低频）+ 常见命题角度 |
| ✍️ 出题 | 中等难度的辨析题（选项之间容易混淆） |

### 🔴 冲刺模式（刷题/考前）

| 板块 | 自适应策略 |
|------|-----------|
| 🎯 直觉 | 直接切到考点语言（"这道题的核心是……"） |
| 📚 原理 | 原理只讲骨架+结论，重点在命题思路和解题套路 |
| ⚠️ 易错 | 多角度易错点对比（"这个点有三种考法……"） |
| 📝 考点 | 精准定位 + 近 3-5 年出现频率 + 预测角度分析 |
| ✍️ 出题 | 出真题变式题或有坑的题，题干可稍长 |

## 纠错四步法 + ⑤ 详细规程

当用户选择题答错时，按以下顺序执行：

```
① 鼓励：      "这个选项很典型" / "这道题确实有陷阱，不怪你"
② 指出错因：   "选项 X 错在……，你误以为……但实际上……"
③ 重讲推理：   从正确前提出发，重新梳理一次正确的推理链条
                （比第一次更精炼，聚焦在关键分歧点）
④ 变式题：     同一个知识点换一个角度出题
                （如上次考定义，这次考计算/比较/应用）
⑤ 关联易错：   列出该知识点在考试中最常见的 2-3 个坑：
                🔴 坑1: ……（每年都有学生在这里丢分）
                🔴 坑2: ……
                🔴 坑3: ……
```

## 完整示例（🟡 复习模式，虚拟内存）

```
🎯 **一句话直觉：**
虚拟内存就是让每个程序觉得自己独享一整块连续的内存空间——即使实际上它的数据可能被拆散放在物理内存的各处、甚至部分在硬盘上。

📚 **原理深讲：**
程序使用的是「虚拟地址」，CPU 发出的地址也是虚拟地址。这个地址经过 **MMU（内存管理单元）** 硬件，去查 **页表**（由 OS 维护的数据结构），转换成真正的「物理地址」去访问内存。

流程：CPU → 虚拟地址 → MMU（查页表）→ 物理地址 → 访问主存
          ↓ 缺页时
       OS 处理缺页中断 → 从磁盘调入页面 → 更新页表 → 重新执行指令

页表的基本结构：页号 | 块号/页框号 | 有效位 | 访问位 | 修改位 | 保护位
多级页表解决了单级页表连续占用大空间的问题……

⚠️ **易错辨析：**
❌ 虚拟内存大小 = 物理内存 + 磁盘交换区
✅ 虚拟内存大小由**地址总线位数**决定（32位→4GB，64位→理论16EB）
页表存在物理内存中，不是存在磁盘上。

📝 **考点定位：**
【OS-内存管理】★★★★★ 每年必考
常见命题：页表结构/地址转换计算/缺页中断处理流程/与TLB联动

✍️ **来道题试试：**
某计算机按字节编址，采用 32 位虚拟地址，页面大小为 4KB，则单级页表中页表项有多少项？
A) 2^10  B) 2^20  C) 2^32  D) 4K

> **你的选择是？**
```

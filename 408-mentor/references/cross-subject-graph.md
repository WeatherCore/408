# 跨科目知识联结点图谱

> 当问题涉及以下联结点时，在主科讲解完成后在回答尾部追加「🔗 拓展链接」提示。
> 格式：`主科视角→关联科：具体关联内容`

---

## 1. 数据结构 ↔ 其他科

| 知识点 | 主科视角 | 关联科 | 关联内容 |
|--------|---------|-------|---------|
| **二叉树遍历** | DS：前/中/后序的递归与迭代 | OS | 进程遍历时也用类似思想（如遍历 PCB 链表） |
| **图的 BFS** | DS：队列实现层序遍历 | 网络 | 路由协议中的 OSPF 使用类似扩散（flooding）机制 |
| **图的 Dijkstra** | DS：求单源最短路 | 网络 | OSPF 协议的核心算法就是 Dijkstra |
| **拓扑排序** | DS：AOV 网的拓扑序列 | OS/CO | 指令流水线中的依赖分析本质是拓扑排序 |
| **哈希表** | DS：冲突处理与查找效率 | OS | 页表查找可用哈希加速；文件系统目录查找也用到哈希 |
| **B+ 树** | DS：多路平衡查找树 | OS/CO | 文件系统的目录结构（如 NTFS 的索引分配）也基于 B+ 树 |
| **排序算法稳定性** | DS：排序算法特性 | OS | 进程调度中的优先级队列实际上是不稳定排序的应用 |

## 2. 计算机组成原理 ↔ 其他科

| 知识点 | 主科视角 | 关联科 | 关联内容 |
|--------|---------|-------|---------|
| **Cache** | CO：映射方式/替换策略/写策略 | OS | 程序局部性原理指导 Cache 优化；OS 的页面置换思想与 Cache 替换同源 |
| **TLB** | CO：CPU 内部的页表缓存 | OS | 虚拟内存地址转换中由 OS 管理页表、CPU 硬件使用 TLB 加速 |
| **MMU** | CO：地址转换硬件单元 | OS | OS 设置页表基址寄存器，MMU 完成虚拟→物理地址翻译 |
| **虚拟内存** | CO：存储层次中的虚拟化实现 | OS | OS 负责页表管理和缺页处理，CO 负责硬件地址转换 |
| **指令流水线** | CO：流水线冒险与处理 | DS | 流水线中的依赖分析可用图论思想（数据依赖图） |
| **中断** | CO：中断请求/响应/处理流程 | OS | OS 的中断处理程序接管硬件中断进行后续处理 |
| **DMA** | CO：直接内存访问硬件 | OS | OS 的 I/O 管理与 DMA 传输配合完成高速数据交换 |
| **浮点 IEEE 754** | CO：浮点数表示标准 | DS | 浮点数比较不能直接用等于、涉及精度误差（数值分析思想） |
| **补码运算** | CO：二进制补码加减法 | DS | 溢出判断本质上是一种逻辑判断（布尔代数） |

## 3. 操作系统 ↔ 其他科

| 知识点 | 主科视角 | 关联科 | 关联内容 |
|--------|---------|-------|---------|
| **进程调度算法** | OS：FCFS/SJF/RR/多级反馈队列 | DS | 调度算法的选择可抽象为排队论模型 + 优先级队列（堆） |
| **信号量/PV 操作** | OS：同步互斥机制 | DS | PV 操作可用整数（信号量）建模，属于数据结构的应用 |
| **银行家算法** | OS：死锁避免 | DS | 安全性检查本质是数组/矩阵运算和状态搜索 |
| **页面置换算法** | OS：LRU/CLOCK/FIFO | CO | 与 Cache 替换算法思想同源，只是时间尺度不同 |
| **缺页中断** | OS：缺页处理流程 | CO | CPU 触发缺页异常，MMU 参与地址检查，OS 完成页面调入 |
| **多级页表** | OS：页表层级结构 | CO | 硬件通过页表基址寄存器定位顶级页表，MMU 逐级遍历 |
| **文件索引分配** | OS：索引结点/inode | DS | 多级索引结构本质上是 B 树的前身/简化版 |
| **磁盘调度** | OS：SSTF/SCAN/C-SCAN | DS | 调度算法的数据结构可抽象为队列（FIFO）或优先队列 |
| **进程状态转换** | OS：三态/五态模型 | CO | 进程切换需要硬件上下文保存（寄存器组），由 CPU 时钟中断驱动 |
| **SPOOLing** | OS：假脱机技术 | CO | 利用中断和 DMA 技术实现慢速设备与快速主机的并行工作 |

## 4. 计算机网络 ↔ 其他科

| 知识点 | 主科视角 | 关联科 | 关联内容 |
|--------|---------|-------|---------|
| **OSPF 协议** | 网络：链路状态路由协议 | DS | Dijkstra 算法是 OSPF 的核心引擎 |
| **RIP 协议** | 网络：距离向量路由 | DS | Bellman-Ford 算法实现（图论最短路径的另一种解法） |
| **TCP 拥塞控制** | 网络：慢启动/拥塞避免/快重传 | OS/DS | 拥塞窗口的调整类似 OS 中资源分配策略；可用控制论建模 |
| **TCP 滑动窗口** | 网络：流量控制机制 | OS/DS | 与数据链路层的 GBN/SR 同源；循环队列数据结构支撑 |
| **CSMA/CD** | 网络：介质访问控制 | OS | 退避算法本质上是一种竞争资源重试策略（类似 OS 锁机制） |
| **DNS 解析** | 网络：域名解析过程 | OS/DS | DNS 缓存机制与 OS 的 Cache 思想相同（时间局部性） |
| **路由表查找** | 网络：最长前缀匹配 | DS | 前缀匹配可用 Trie 树（字典树/基数树）高效实现 |
| **ARP 协议** | 网络：IP→MAC 地址映射 | OS | ARP 缓存的过期/更新策略与 OS 缓存管理思想一致 |
| **分组交换/存储转发** | 网络：分组交换原理 | OS | 路由器缓存分组->处理->转发，本质是生产者-消费者问题 |
| **端口号** | 网络：传输层复用/分用 | OS | 端口号管理类似 OS 中的资源标识号管理（如文件描述符） |

## 5. 多科大联结点（🔥 考研高频综合题素材）

以下知识点是 408 综合题（大题）的常见跨科出题角度：

| 联结点 | 涉及科目 | 典型综合题套路 |
|--------|---------|--------------|
| **虚拟内存 + Cache + TLB** | OS + CO | 给出虚拟地址→经过 TLB→查页表→得到物理地址→再查 Cache→得到数据 |
| **进程调度 + 优先级队列** | OS + DS | 用堆实现就绪队列，进程切换时调整优先级 |
| **路由协议 + 图算法** | 网络 + DS | OSPF 用 Dijkstra 算最短路径树、RIP 用 Bellman-Ford |
| **文件系统 + B+ 树** | OS + DS | 文件索引分配的多级指针/C 盘 FAT 结构与 B+ 树思想的联系 |
| **TCP 拥塞控制 + 滑动窗口** | 网络 + OS | 拥塞窗口 vs 接收窗口 vs 发送窗口的协同 |
| **流水线 + 数据依赖 + 图** | CO + DS | 数据依赖图/控制依赖图分析流水线停顿 |
| **缺页处理 + 中断机制 + DMA** | OS + CO | 缺页中断处理流程中 OS 与硬件的配合 |

# 408 考纲大纲（四科完整结构）

> 基于教育部考研408统考大纲整理，用于知识体系锚定和章节定位。

---

## 一、数据结构

### 1. 线性表
- 线性表的定义和基本操作
- 线性表的顺序存储（顺序表）与链式存储（单链表、双链表、循环链表）

### 2. 栈、队列和数组
- 栈（顺序栈、链栈）与队列（顺序队列、循环队列、链队）的基本概念和操作
- 栈和队列的应用（括号匹配、表达式求值、层次遍历）
- 特殊矩阵的压缩存储（对称矩阵、三角矩阵、稀疏矩阵）

### 3. 树与二叉树
- 二叉树的概念、性质、存储（顺序、链式）
- 二叉树的遍历（前序、中序、后序、层次）与线索二叉树
- 树与森林的存储与遍历（双亲表示法、孩子表示法、孩子兄弟表示法）
- **哈夫曼树**（最优二叉树）与哈夫曼编码
- 并查集及其应用
- 二叉排序树（BST）、平衡二叉树（AVL）、红黑树

### 4. 图
- 图的基本概念（有向图、无向图、连通性、度）
- 图的存储（邻接矩阵、邻接表、十字链表、邻接多重表）
- 图的遍历（DFS、BFS）
- 最小生成树（Prim、Kruskal）
- 最短路径（Dijkstra、Floyd）
- 拓扑排序与关键路径（AOV、AOE）

### 5. 查找
- 顺序查找、折半查找、分块查找
- B 树与 B+ 树的基本概念与操作
- 散列表（哈希表）—— 哈希函数构造、冲突处理（开放地址法、链地址法）、装填因子与性能分析

### 6. 排序
- 插入排序（直接插入、折半插入、希尔排序）
- 交换排序（冒泡排序、快速排序）
- 选择排序（简单选择、堆排序）
- 归并排序（二路归并）
- 基数排序
- 各种排序算法的时空复杂度、稳定性、适用场景对比

## 二、计算机组成原理

### 1. 计算机系统概述
- 计算机发展历程与分类
- 计算机系统层次结构（硬件、微程序、ISA、OS、高级语言）
- 计算机性能指标（吞吐量、响应时间、CPU时钟周期、主频、CPI、MIPS、FLOPS）

### 2. 数据的表示和运算
- 数制与编码（原码、反码、补码、移码）
- 定点数的表示与运算（加减乘除）
- 浮点数的表示与运算（IEEE 754 标准）
- 算术逻辑单元 ALU

### 3. 存储系统
- 存储器的分类与层次结构（Cache-主存-辅存三级）
- 半导体随机存取存储器（SRAM、DRAM、ROM）
- 主存储器（地址译码、芯片扩展、多模块存储器）
- **Cache**（映射方式、替换算法、写策略、命中率与平均访问时间计算）
- **虚拟存储器**（页式、段式、段页式，TLB 快表）

### 4. 指令系统
- 指令格式（定长/变长操作码、地址码结构）
- 寻址方式（立即、直接、间接、寄存器、相对、基址、变址）
- CISC vs RISC

### 5. 中央处理器 CPU
- CPU 的功能与基本结构（ALU、寄存器组、控制器）
- 数据通路（单总线/多总线结构、指令执行流程）
- 控制器（硬布线控制器、微程序控制器、微指令编码方式）
- 指令流水线（流水线基本概念、数据冒险/控制冒险/结构冒险、冒险处理）

### 6. 总线
- 总线的基本概念与分类（系统总线、I/O 总线、通信总线）
- 总线仲裁（集中式：链式查询、计数器查询、独立请求）
- 总线操作与定时（同步/异步定时）

### 7. 输入/输出系统
- I/O 接口（功能与结构、端口编址）
- I/O 控制方式（程序查询、中断驱动、DMA 方式）
- 中断系统（中断请求、响应、判优、处理过程）

## 三、操作系统

### 1. 操作系统概述
- OS 的概念、特征（并发、共享、虚拟、异步）与功能
- OS 的发展历程与分类（批处理、分时、实时、分布式）
- 系统调用（用户态 vs 核心态、访管指令）

### 2. 进程管理
- **进程与线程**（PCB、进程状态转换、线程模型）
- **CPU 调度**（调度算法：FCFS、SJF、优先级、RR、多级反馈队列）
- 同步与互斥（临界区、信号量、PV 操作、经典同步问题：生产者-消费者、读者-写者、哲学家进餐）
- 死锁（必要条件、预防、避免（银行家算法）、检测与解除）

### 3. 内存管理
- 内存管理基础（分区的分配与回收、覆盖与交换）
- **分页管理**（页表结构、地址转换、TLB、多级页表）
- **分段管理与段页式管理**
- **虚拟内存**（请求分页、缺页中断、页面置换算法——OPT/FIFO/LRU/CLOCK/改进型CLOCK）、页面分配策略

### 4. 文件管理
- 文件与文件系统的基本概念
- 文件的逻辑结构与物理结构（连续/链接/索引分配）
- 目录管理（FCB、目录结构、文件共享）
- 磁盘管理（磁盘调度算法——FCFS/SSTF/SCAN/C-SCAN、磁盘读写时间计算）

### 5. 输入/输出管理
- I/O 软件层次结构（用户层→设备独立性层→设备驱动层→中断处理层）
- 缓冲区管理（单缓冲、双缓冲、循环缓冲、缓冲池）
- SPOOLing 技术

## 四、计算机网络

### 1. 计算机网络体系结构
- 网络的概念、组成与分类
- 分层模型（OSI 七层、TCP/IP 四层）
- 数据交换方式（电路交换、报文交换、分组交换）

### 2. 物理层
- 通信基础（信源/信宿/信道、奈氏准则、香农定理）
- 传输介质（双绞线、同轴电缆、光纤、无线）
- 物理层设备（中继器、集线器）

### 3. 数据链路层
- 功能概述（成帧、差错控制、流量控制、介质访问控制）
- 差错控制（CRC 循环冗余校验、海明码）
- 流量控制与可靠传输机制（停止-等待、GBN 后退 N 帧、SR 选择重传）
- **介质访问控制**（CSMA/CD、CSMA/CA、令牌传递）
- 局域网与以太网（MAC 地址、以太网帧格式、交换机工作原理）
- **PPP 协议**与 HDLC 协议
- 数据链路层设备（网桥、交换机）

### 4. 网络层
- 网络层功能（路由与转发、拥塞控制）
- **IPv4**（分类编址、子网划分、CIDR、NAT、ARP、DHCP、ICMP）
- **IPv6**（基本概念与地址格式）
- **路由协议**（RIP 距离向量、OSPF 链路状态、BGP 路径向量）
- IP 组播与移动 IP
- 网络层设备（路由器）

### 5. 传输层
- 传输层功能（复用/分用、可靠传输）
- **UDP**（报文格式、校验、适用场景）
- **TCP**（报文格式、连接管理——三次握手四次挥手、流量控制——滑动窗口、拥塞控制——慢启动/拥塞避免/快重传/快恢复、超时重传）

### 6. 应用层
- 应用层模型（C/S、P2P）
- **DNS**（域名解析过程、递归/迭代查询）
- **FTP**（控制连接与数据连接）
- **电子邮件**（SMTP、POP3、IMAP、MIME）
- **WWW 与 HTTP**（HTTP 报文格式、Cookie、持久连接/非持久连接）
